Frequently asked questions

Did not find your answer? Ask in the support forum.

Did you rename the plugin?

Yes. It was called CF7 to Zapier and changed its name because of the trademark rules of WordPress.org.

Does it work with the block editor (Gutenberg)?

Yes. It works with WordPress 5.0 or later and with the current versions of Contact Form 7.

Does it work with forms not made with Contact Form 7?

No. It only sends Contact Form 7 forms.

Can I use it without Zapier?

Yes. Zapier is one option, but any URL that receives data works. By default, the plugin sends JSON.

My data arrives empty or does not arrive.

See Troubleshoot missing data. If that does not help, ask in the support forum.

How can I send one form to multiple webhooks?

Add one URL per line in Webhook URL. If one of them fails, the next ones are not sent; see Make multiple webhooks optionals.

How can I show webhook errors on the form?

Request errors already show the form error message. To show the error itself or treat other responses as errors, see Handle webhook errors.

How can I send uploaded files?

The plugin copies each file before Contact Form 7 deletes it and sends its link, or sends the file content with Send content. See Send files.

You can also add the files to the media library, as private media, and delete them after a number of days. See Media library.

How can I delete uploaded files?

Use Delete all files in Media, under Advanced settings. It deletes every file uploaded with the form, including the ones in the media library. Links already sent to webhooks stop working. Only administrators can use it.

How can I rename a field sent to the webhook?

Add a webhook option to the form tag: [text your-field class:form-control webhook:webhook-key] is named your-field in the form and arrives as webhook-key. See Rename the fields sent to the webhook.

How can I get the free text value?

The plugin sends the text typed in the free text option in place of the last option, for checkboxes and radios. See Get the free text of checkboxes and radios.

Can I send webhooks to an internal or private IP address?

Not by default: requests to private, loopback and link-local addresses are blocked to prevent SSRF attacks. To allow a trusted host, see Send webhooks to an internal IP address.

I don't see a template for my webhook.

Templates come from the community, so the list grows as people add to it. You can still write the headers and the body yourself, or propose a template.

Does it work with Contact Form 7 Multi-Step Forms?

Yes. Set the webhook in the last step and the plugin sends the data of every step, with no hidden fields. See Use with Multi-Step Forms.

Who is the developer?
