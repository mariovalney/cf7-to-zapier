Use with Multi-Step Forms

The plugin supports Contact Form 7 Multi-Step Forms. Set the webhook only in the form of the last step: the plugin adds the data of the previous steps, stored by Multi-Step Forms, to the last one. You do not need hidden fields.

The data comes from what Multi-Step Forms stores, so the plugin cannot guarantee it. If a step is missing, check that plugin first.

Turn it off

To send only the fields of the last step, add this code as explained in Add custom code:

add_filter( 'ctz_get_data_from_cf7msm_posted_data', '__return_false' );
