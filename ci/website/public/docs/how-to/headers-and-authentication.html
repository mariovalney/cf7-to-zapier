Documentation / How-to

Add headers and authentication

Write the headers in Headers, under Advanced settings, one per line, with the name and the value separated by a colon:

Authorization: Bearer 99999999999999999999
X-API-Key: your-key

For basic authentication, send Authorization: Basic followed by user:password encoded in base64.

Form data in headers

Header values accept form fields and special mail tags. Special mail tags work here without adding them to Special Mail Tags:

X-User-Email: [your-email]
X-Client-IP: [_remote_ip]

Since 5.2.0, line breaks in those values are replaced by spaces, so a visitor cannot add headers of their own.

Content type

The plugin sends Content-Type: application/json, or text/plain when the body is not JSON, with the site charset. A Content-Type line in Headers replaces it; write the name exactly like that.

Keep the secrets safe

Headers are saved in the form settings, so anyone who can edit the form can read them. Error notification emails hide the values of Authorization, X-API-Key, Api-Key, X-Auth-Token and Cookie; other headers appear as sent.
