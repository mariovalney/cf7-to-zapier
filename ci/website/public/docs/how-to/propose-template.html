Propose a template

Templates are a list of header and body presets in ci/website/public/templates.json, in the GitHub repository. Each one looks like this:

{
    "name": "Slack Webhook",
    "headers": [ "x-example: custom-value" ],
    "body": "{ \"text\": \"*New message!*\\n\\n__VALUES__\" }",
    "separator": "\\n",
    "docs": "https://api.slack.com/messaging/webhooks"
}
  • name and body are required.
  • __VALUES__ in the body is replaced by the fields of the form, joined by separator (" | " by default).
  • headers is a list of headers, one per item.
  • docs links to the documentation of the service.

Open a pull request adding your template to the default list, or an issue describing it. Once merged, every site sees it in the template selector. See Templates.
