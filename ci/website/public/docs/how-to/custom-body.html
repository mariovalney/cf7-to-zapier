Create a custom body

By default, the webhook gets a JSON object with every field and special mail tag. To send something else, write the body in Body, under Advanced settings.

Write the body

Use the fields as in a Contact Form 7 mail, between brackets. Names are case sensitive. Strings need your own quotes; checkbox and acceptance fields go without quotes, since they become a JSON array and a number:

{
    "composed-message": "Sir [your-name] from [your-city].",
    "text-field": "[your-name]",
    "checkbox-field": [your-checkbox],
    "radio-field": "[your-choice]"
}

The plugin escapes the values for JSON, so quotes or line breaks typed in the form do not break the body. An empty checkbox becomes [] and an unchecked acceptance becomes 0.

Inside quotes, a checkbox or multiple select becomes text, with the options separated by commas as in a Contact Form 7 mail. Since 5.3.1, "Found us by: [your-checkbox]" sends "Found us by: Google, Friend". Before that version, it made the body invalid JSON.

Fields renamed with the webhook option are used by their new key. A name that matches no field stays in the body as written.

Check the result

Save the form and open Body again: the preview shows what will be sent, with example values. If the body is not valid JSON, the plugin sends it as plain text, with Content-Type: text/plain.

Templates fill this field for you. See Templates.
