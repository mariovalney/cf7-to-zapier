Rename the fields sent to the webhook

Each field is sent with its name as the key: [email* your-email] arrives as your-email. To use another key, add a webhook option to the form tag:

[email* your-email webhook:email]

Now the webhook gets email. The option works with the other options of the tag:

[text your-field class:form-control id:field-id webhook:webhook-key]

This field is named your-field in the form and arrives as webhook-key.

In a custom body or in headers

After renaming, use the new key: [email], not [your-email]. See Create a custom body.

Special mail tags

Special mail tags take the key as a second word, as in [_post_title title]. See Send special mail tags.
