Use form fields in the webhook URL

The webhook URL accepts the same placeholders as a mail body. Each one is replaced by the field value, URL-encoded:

https://example.com/hook?email=[your-email]&plan=[your-plan]

Checkbox values are joined with |. For a select with pipes, such as "Pro plan|pro", the URL gets the value: pro. Special mail tags work too, and a placeholder that matches no field becomes empty.

Keep placeholders in the path or the query. In the domain, a visitor would choose where the data goes.

Send the page URL parameters

To pass a parameter of the page where the form is, such as utm_source in https://example.com/?utm_source=example, add a hidden field that takes its value from the URL:

[hidden utm_source default:get]

The field is sent like any other, and can also go in the webhook URL as [utm_source].

With code

The ctz_hook_url_placeholder filter changes how a value goes into the URL, and ctz_hook_url changes the final URL. Add the code as explained in Add custom code:

add_filter( 'ctz_hook_url', function( $hook_url, $data ) {
    return add_query_arg( 'source', 'website', $hook_url );
}, 10, 2 );
