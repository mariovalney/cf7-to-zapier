Documentation / How-to

Send files

Contact Form 7 deletes uploads at the end of the request, so the plugin handles files before that.

As links

By default, each file is copied to wp-content/uploads/cf7-to-webhook-uploads/<form ID>/<date>_<random>/ and the webhook gets its URL. A field with one file sends a string; several files send an array of URLs.

As content

With Send content checked, in Files, the webhook gets the file itself, with no copy kept on the site:

{
    "your-file": {
        "filename": "photo.jpg",
        "content": "/9j/4AAQSkZJRgABAQ..."
    }
}

The content is base64, so the destination has to decode it. The body grows by about a third of the file size, and many services limit the size of what they receive. Error emails include the request body, with the file content.

Keep or delete the files

To keep copies in the media library, or to delete files after some days or all at once, see Media library.

Multiple files per field work with the MultiLine files for Contact Form 7 plugin.
