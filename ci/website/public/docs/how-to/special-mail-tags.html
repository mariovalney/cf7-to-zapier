Send special mail tags

Contact Form 7 has special mail tags for data that is not a field, such as [_post_title], [_remote_ip], [_date] and [_url]. To send them, add them to Special Mail Tags:

[_post_title]
[_remote_ip]
[_date]

Each tag arrives with its name as the key, such as _remote_ip. A second word sets another key:

[_remote_ip ip]
[_post_title page]

In headers, special mail tags work without being listed here. See Add headers and authentication.

The label of a pipe option

With pipes, an option shows a label and sends a value:

[select your-plan "Basic plan|basic" "Pro plan|pro"]

The webhook gets basic. To also send the label the visitor chose, add the field with the _raw_ prefix to Special Mail Tags:

[_raw_your-plan plan-label]

Now the data also has plan-label with Basic plan.
