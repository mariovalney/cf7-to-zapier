Troubleshoot missing data

Nothing arrives

  • Check that Send to Webhook is on and the URL is saved in Webhook URL.
  • The plugin sends the webhook only after Contact Form 7 accepts the submission. Validation errors, spam protection (reCAPTCHA, Akismet and others) or a failed Contact Form 7 email, when Send CF7 mail as usually is checked, stop it.
  • Forms sent by other plugins are not supported, only Contact Form 7 forms.
  • The site blocks requests to private and local addresses. See Send webhooks to an internal IP address.
  • If the webhook failed, the plugin emailed the error to the addresses in Errors. See Handle webhook errors.

Fields arrive empty or missing

  • In a custom body, names are case sensitive and must match the fields, or their new key when renamed with the webhook option.
  • Strings in a custom body need quotes; checkbox and acceptance fields do not. See Create a custom body.
  • With Multi-Step Forms, the settings go in the last step. See Use with Multi-Step Forms.

See the request

Point the webhook to a request inspector, such as webhook.site, and submit the form: you see exactly what the plugin sends. If you still need help, open a topic in the support forum with the error email, after removing personal data and keys.
