Send webhooks to an internal IP address

By default, the plugin blocks requests to private, loopback and link-local addresses (such as 192.168.x.x, 10.x.x.x, 127.0.0.1 and 169.254.x.x) to prevent SSRF attacks.

To reach a trusted internal service, allow its host with the http_request_host_is_external filter of WordPress. Add the code as explained in Add custom code:

add_filter( 'http_request_host_is_external', function( $external, $host ) {
    $trusted = [ '192.168.1.100', '10.0.0.50' ];

    return in_array( $host, $trusted, true ) ? true : $external;
}, 10, 2 );

Replace the addresses in $trusted with the hosts to allow. Only do this on servers you control and trust.
