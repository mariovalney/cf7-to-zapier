Send a GET request

In Method, under Advanced settings, choose GET. The data goes as query parameters in the URL instead of a body.

The body must be JSON: the default body is, and a custom body has to be a JSON object. Otherwise the request is not sent and the plugin reports the error "Webhook has method GET but body is not a JSON to be passed as query params."

Lists, such as checkbox values, go in the PHP style: your-checkbox[0]=a&your-checkbox[1]=b, URL-encoded.

For a few fields, placeholders in the webhook URL may be simpler. PUT, PATCH and DELETE send the body like POST.
