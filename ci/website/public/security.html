Security

How to report a vulnerability in CF7 to Webhook, and the people who reported one responsibly.

Report a vulnerability

Report it privately on GitHub, in Report a vulnerability. Only the maintainer sees the report. Do not open a public issue or a topic in the support forum: anyone could use the details before the fix is released.

Include the plugin version, the steps to reproduce and what an attacker can do with it. Say how you want to be credited.

Fixes go out as a new version on WordPress.org, and only the latest version gets them. The changelog of that version credits the reporter.

Acknowledgments

The people who reported a vulnerability responsibly are listed in Acknowledgments, after the fix.
