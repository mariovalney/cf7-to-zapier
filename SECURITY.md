# Security policy

Report vulnerabilities privately on GitHub, in [Report a vulnerability](https://github.com/mariovalney/cf7-to-zapier/security/advisories/new). Do not open a public issue or a topic in the support forum.

Include the plugin version, the steps to reproduce and what an attacker can do with it. Say how you want to be credited.

Only the latest version on WordPress.org gets security fixes. The people who reported vulnerabilities are listed at [cf7-to-webhook.valney.dev/security](https://cf7-to-webhook.valney.dev/security).
